
# Port Status Checker

## Project Description
A Python-based cybersecurity tool that checks whether a specific TCP port on a given host is open, closed, or unreachable.

## Features
- Accepts IP address or hostname.
- Accepts port number from the user.
- Checks TCP connection status.
- Identifies common network services.
- Handles invalid inputs and connection errors.
- Uses a connection timeout.

## Technologies Used
- Python 3
- Socket Module
- Python IDLE

## How to Run
1. Download the Python file.
2. Open it in Python IDLE.
3. Press F5.
4. Enter the target IP address or hostname.
5. Enter the port number.
6. View the connection status.

## Objective
To understand TCP networking, port communication, and basic network security concepts.

## Disclaimer
Use this tool only on your own systems or systems for which you have explicit authorization.
